# Smart Crop Advisory System

## Project Description
Smart Crop Advisory System for Small and Marginal Farmers helps farmers make better crop decisions by considering soil conditions, season, and farming requirements.

## Objective
To assist farmers in selecting the right crop for better productivity.

## Users
- Farmers
- Agricultural Advisors (Future Scope)

## Modules
### 1. Crop Recommendation Module
Recommends suitable crops based on soil type and season.

### 2. Soil Information Module
Provides information about different soil types and their suitability for crops.

### 3. Fertilizer Recommendation Module
Suggests fertilizers based on crop and soil requirements.

### 4. Crop Information Module
Provides basic information about crops, cultivation methods, and benefits.

### 5. User Interface Module
Allows users to interact with the system and receive recommendations.

## Future Enhancements
- Weather-based crop recommendations
- Crop disease detection
- Yield prediction using Machine Learning
- Mobile application support
