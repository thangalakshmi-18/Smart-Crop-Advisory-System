# Smart Crop Advisory System

## About the Project

This project is developed to help small and marginal farmers select suitable crops based on farming conditions. The system aims to provide simple crop recommendations that can support better agricultural decisions and improve productivity.

## Objective

To assist farmers in selecting the right crop for better productivity.

## Problem Definition

Small and marginal farmers often face difficulties in selecting suitable crops based on soil type, season, and available resources. Incorrect crop selection can reduce productivity and income. This project aims to help farmers make better crop decisions through simple crop recommendations.


## Modules

* Crop Recommendation
* Soil Information
* Fertilizer Suggestion
* Crop Details
* User Interface

## Future Scope

* Weather-based recommendations
* Crop disease identification
* Yield prediction
* Mobile application development
